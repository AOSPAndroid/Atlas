OFFICE ATLAS + IT 6.4 - CHANGELOG
Release date: 2026-09-08
Applies to the real Atlas application only. Standalone read-only demo unchanged.

ADDED: PROGRESSIVE LIVE MACHINE HEALTH
Selecting a machine loads independent results for WMI, C$ access, ping,
CPU model/core counts/current utilisation, installed and usable RAM/current
usage, GPU adapter names, C: storage total/free, Windows version, uptime
and last boot. Each check appears when ready with its own check timestamp.
Slow or unavailable hardware queries do not hold up successful checks.
Missing data shows Unavailable rather than zero or a healthy result.
Late results from previous selections/refreshes do not update the new target.
Refresh health reruns checks (completed results may be reused for five seconds).
Concurrent duplicate checks are shared and remote query timeouts are bounded.
GPU names may include virtual or remote display adapters. GPU VRAM is not
reported. Memory and disk sizes are GiB; usable RAM can differ from installed
RAM because Windows reserves some memory. CPU utilisation is a sampled value.

ADDED: MACHINE SPECIFICATIONS
IT console machine menu: right-click > View specifications.
Desk-view machine card: right-click opens the same specifications panel.
Results are live queries using the operator account, not Excel inventory.

ADDED: RELATIONSHIP BADGES
Assigned and Last logged-on badges use their separate extract relationships.
Both badges appear when the selected user matches both fields.
For direct machine results, badges include the recorded person's name.
Last logged-on is historical inventory evidence, not most frequent use or
proof of the current signed-in user. Assigned is not proof of current use.

INCLUDED: SCRIPT-NAME COMPATIBILITY FIX
Case-insensitive PS1/VBS detection includes these ending suffixes:
Install: _i, _install, _installs
Uninstall: _u, _uninstall, _uninstalls
Repair: _r, _repair, _repairs
Nested package directories are supported. The same rules are used by the
catalogue, script selector and deployment validation. Uninstall scripts
cannot pass Install validation. No separate patch is needed for this release.

DEFERRED
The intermittent installed-software inventory failure is not changed in
this release. No retry or cache changes were made to that feature.
No updates to the standalone read-only demo.

UPGRADE / KEEP YOUR DATA
1. Finish active deployment jobs, then stop the real Atlas application.
2. Back up the complete existing office_atlas.db using the app backup or
   SQLite backup facilities. Do not rely on a seating-only export.
3. Rename the new embedded TXT to .py and run it. It extracts into a separate
   folder and does not overwrite an existing installation.
4. Replace the new folder's seeded office_atlas.db with your complete backup.
5. Carry across Python_Settings.bat and config.json. Preserve any customised
   launcher host/port settings; compare launcher.py rather than copying the
   entire old source tree over the release. External installers stay in the
   existing package repository.
6. Start the real Atlas and reload the browser. Keep the old folder until
   your map, users, machines and settings have been checked.
The embedded TXT includes app code, maps, assets, templates, tests and a
seeded database. Python, Python dependencies and external installers are not
embedded. The full IT server remains restricted to localhost by default.

VALIDATION
Python/JavaScript syntax, progressive UI state tests, relationship badges,
script suffix/action matching and package extraction integrity checked.
Live Windows/WMI hardware queries require validation on a designated target;
this build environment cannot run Windows PowerShell or reach your domain.
Full rendered-browser validation is not available in this build environment.
